# Vision-Based-Driver-Monitoring-and-Drowsiness-Detection-System-
Vision-Based Driver Monitoring and Drowsiness Detection System using OpenCV, MediaPipe, STM32F429, and ESP32. Implements EAR-based drowsiness detection, multi-level LED/buzzer alerts, LCD touch interface, SPI communication, web monitoring, auto-calibration, live EAR visualization, and CSV event logging.
